## 🚀 SEO-optimierte, responsive Portfolio-Website mit Next.js

Diese moderne Portfolio-Webseite wurde mit **Next.js** entwickelt und ist vollständig **SEO-optimiert** und **responsive**, um sowohl auf Desktop- als auch auf Mobilgeräten eine optimale Benutzererfahrung zu bieten. Das Projekt beinhaltet verschiedene Abschnitte wie **Navbar**, **Einführung**, **Portfolio**, **Services**, **Testimonials**, **Footer** und eine **Kontaktseite**. Zudem wurde die Datenabrufung mit **getStaticProps** und **getStaticPaths** implementiert, um statische Inhalte effizient bereitzustellen. Am Ende wird die Anwendung für den produktiven Einsatz **deployt**.  

### 🛠️ Verwendete Technologien
- **Next.js**  
- **React.js**  
- **CSS / Tailwind CSS**  
- **JavaScript (ES6+)**  
- **Node.js**  
- **Vercel Deployment**
